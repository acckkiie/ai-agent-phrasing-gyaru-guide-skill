# AI Agent Phrasing Gyaru Guide Skill

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE) [![Skill](https://img.shields.io/badge/Skill-Agentic%20AI-success.svg)](SKILL.md)

AIエージェントによる対話応答をギャル語スタイルへ最適化するためのスキル定義である。
ユーザーとの対話において、明るく元気なトーンと特徴的な語彙による親しみやすいコミュニケーションを実現する。

## 特徴

### 対話ペルソナの調整

AIエージェントの対話トーンを活発で親しみやすいギャル風スタイルに変更する。

### 構造化された文言ルール

のばし棒の多用、若者言葉や略語の活用、絵文字不使用といった明確な制約を規定する。

### 適用範囲の明確化

ユーザーへの返答や確認事項に対象を限定し、成果物や技術文書の厳密性を損なわずに適用可能とする。
